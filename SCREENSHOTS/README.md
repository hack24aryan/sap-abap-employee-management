# Screenshots

This folder is reserved for screenshots of the SAP system.

## How to Take Screenshots

1. **Selection Screen:** When the report's selection screen appears, press `Print Screen` or use the Snipping Tool.
2. **Report Output:** After executing the report, capture the output display.
3. **SE11 Table:** Take a screenshot of the ZEMPLOYEE table definition in SE11.
4. **SE16N Data:** Take a screenshot of the data in SE16N.
5. **Debugger:** Take a screenshot while debugging with variable values visible.

## Suggested Screenshots

- `01_selection_screen.png` — The selection screen of ZEMPLOYEE_REPORT
- `02_report_output.png` — Employee report output
- `03_department_report.png` — Department summary output
- `04_se11_table.png` — ZEMPLOYEE table definition in SE11
- `05_se16n_data.png` — Sample data in SE16N
- `06_debugger.png` — Debugger showing internal table contents

> **Note:** Screenshots should be added after running the programs in a real SAP system. These cannot be generated without access to an SAP environment.
